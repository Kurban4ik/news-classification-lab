# Подготовка данных и моделей

Lenta.ru: 800 975 строк CSV, из которых 738 973 имеют рубрику. BM25 reference-корпус содержит 618 518 новостей, CatBoost train — 68 725, test — 51 730. TF-IDF обучается на полной train-части с непустыми текстами; словарь содержит 583 280 терминов.

Положите `lenta-ru-news.csv` в `data/raw/`.

Для BM25 нужны Java 21+ и Anserini JAR, поставляемый с Pyserini. CatBoost обучается на GPU. Локальные индексы и соседей можно переиспользовать; при отсутствии индексов ноутбук строит их по полным данным.

Данные и большие модели не входят в Git-репозиторий. Пути и параметры задаются в начале `project.ipynb`; ноутбук обрабатывает полные наборы данных.

Датасет: [Lenta.Ru News Dataset](https://github.com/yutkin/Lenta.Ru-News-Dataset).
